## まず結論：大東建託の初期費用は3つに分かれる {#conclusion}

大東建託物件の初期費用は、次の3つを足した金額です。

1. **大東建託パートナーズに支払う初期費用**
2. **前家賃**
3. **仲介業者に支払う費用**

ここで一番大切なのは、同じ物件を同じ入居日・同じ契約条件で借りる場合、①と②はどの仲介業者から申し込んでも基本的に同じという点です。

一方、③の仲介手数料やオプション費用は、窓口となる仲介業者によって変わります。

つまり、大東建託物件の初期費用を比較するときは、③の「仲介業者に支払う費用」を確認することが重要です。

## 今回の計算条件 {#conditions}

今回は、次の物件を例に初期費用を計算します。

| 項目 | 条件 |
| --- | ---: |
| 家賃 | 85,000円 |
| 駐車場使用料 | 6,600円 |
| 共益費 | 3,500円 |
| 入居日 | 月の1日 |
| 敷金 | 0円 |
| 礼金 | 127,500円 |
| クリーニング費 | 80,000円 |

礼金は物件によって異なり、クリーニング費は間取りなどによって金額が変わります。

そのため、以下の金額はすべての大東建託物件に共通する金額ではなく、家賃8万5,000円の物件を月の1日から契約する場合の一例です。

## ① 大東建託パートナーズに支払う初期費用 {#partners}

まずは、大東建託パートナーズに支払う費用です。

| 項目 | 金額 |
| --- | ---: |
| 礼金 | 127,500円 |
| 敷金 | 0円 |
| クリーニング費 | 80,000円 |
| 契約保証委託料 | 25,000円 |
| 鍵セット費 | 3,300円 |
| 火災保険料 | 0円 |
| **合計** | **235,800円** |

### 敷金

今回の物件では、敷金は0円です。

敷金の代わりに、契約時にクリーニング費を支払う形になっています。

### クリーニング費

今回のクリーニング費は8万円です。

クリーニング費は間取りなどによって金額が変わるため、物件情報や見積書で確認する必要があります。

### 契約保証委託料

今回の契約保証委託料は2万5,000円です。

ペット不可物件の場合は2万2,000円となるケースがあります。

### 鍵セット費

鍵セット費は3,300円です。

### 火災保険料

今回の契約例では、別途の火災保険料はかかりません。

## ② 前家賃 {#advance-rent}

次に、入居する月の家賃や月額費用です。

今回は月の1日から入居するため、日割りではなく1カ月分で計算します。

| 項目 | 金額 |
| --- | ---: |
| 家賃 | 85,000円 |
| 駐車場使用料 | 6,600円 |
| 共益費 | 3,500円 |
| ruumサポート | 1,680円 |
| 町内会費 | 300円 |
| 月額保証委託料 | 2,599円 |
| **合計** | **99,679円** |

月の途中から入居する場合は、契約開始日によって家賃などの計算が変わります。

同じ物件でも入居日が違えば初期費用の総額も変わるため、見積もりを比較するときは入居日をそろえる必要があります。

## ③ 仲介業者に支払う費用 {#agency}

最後に、窓口となる仲介業者へ支払う費用です。

| 項目 | 計算方法 | 金額 |
| --- | --- | ---: |
| 仲介手数料 | 家賃85,000円×1.1 | 93,500円 |
| 駐車場手数料 | 駐車場6,600円×1.1 | 7,260円 |
| その他オプション | 仲介業者による | 未定 |
| **オプションを除く合計** |  | **100,760円** |

大東建託物件の場合、仲介手数料は家賃の1.1カ月分、駐車場手数料は駐車場代の1.1カ月分となっていることが多いです。

ただし、実際の金額や条件は仲介業者によって異なります。

また、仲介業者によっては、次のようなオプションが見積もりに含まれることがあります。

- 抗菌施工
- 害虫駆除
- 消火用具
- その他の入居サポート

これらのオプション内容や金額も、仲介業者によって変わります。

## 初期費用の合計は43万6,239円 {#total}

ここまでの金額を合計します。

| 支払先・費用 | 金額 |
| --- | ---: |
| ① 大東建託パートナーズに支払う費用 | 235,800円 |
| ② 前家賃 | 99,679円 |
| ③ 仲介業者に支払う費用 | 100,760円 |
| **合計** | **436,239円** |

したがって、今回の物件の初期費用は、仲介業者の追加オプションを除いて**43万6,239円**です。

抗菌や害虫駆除などを追加する場合は、その金額がさらに加算されます。

なお、ペット不可物件で契約保証委託料が2万2,000円となる場合は、合計金額が3,000円下がり、**43万3,239円**となります。

## 初期費用を比較するポイント {#comparison}

大東建託物件の見積もりを比較するときは、すべての費用が変わるわけではありません。

### どこで借りても基本的に同じ部分

同じ物件・同じ入居日・同じ契約条件であれば、次の部分は基本的に同じです。

- 大東建託パートナーズに支払う費用
- 家賃
- 駐車場使用料
- 共益費
- ruumサポート
- 町内会費
- 月額保証委託料

### 仲介業者によって変わる部分

比較するべきなのは、主に次の部分です。

- 仲介手数料
- 駐車場手数料
- 抗菌施工
- 害虫駆除
- その他のオプション費用

見積書を比較するときは、総額だけを見るのではなく、①②③に分けて確認すると、どの部分に差があるのかが分かりやすくなります。

## まとめ

大東建託物件の初期費用は、次の3つでできています。

1. 大東建託パートナーズに支払う初期費用
2. 前家賃
3. 仲介業者に支払う費用

今回の家賃8万5,000円の物件では、オプションを除いた初期費用は**43万6,239円**でした。

同じ物件を同じ条件で借りる場合、①と②はどの窓口でも基本的に同じです。

初期費用に差が出やすいのは、③の仲介手数料・駐車場手数料・抗菌や害虫駆除などのオプションです。

大東建託物件の初期費用を比較するときは、仲介業者へ申し込む前に、③の内容を確認することが大切です。

※掲載している金額は一例です。礼金、クリーニング費、保証料、月額費用などは物件や契約条件によって異なる場合があります。正式な金額は、物件ごとの見積書でご確認ください。
