## まず結論：大東建託の初期費用は3つに分かれる {#conclusion}

大東建託物件の初期費用は、次の3つを足した金額です。

1. **大東建託パートナーズに支払う初期費用**
2. **前家賃**
3. **仲介業者に支払う費用**

ここで一番大切なのは、同じ物件を同じ入居日・同じ契約条件で借りる場合、①と②はどの仲介業者から申し込んでも基本的に同じという点です。

一方、③の仲介手数料やオプション費用は、窓口となる仲介業者によって変わります。

つまり、大東建託物件の初期費用を比較するときは、③の「仲介業者に支払う費用」を確認することが重要です。

## 今回の計算条件 {#conditions}

今回は、次の条件のペット共生物件を例に、2027年1月11日までに申し込む場合と1月12日以降に申し込む場合の費用を計算します。

| 項目 | 条件 |
| --- | ---: |
| 家賃 | 85,000円 |
| 駐車場使用料 | 6,600円 |
| 共益費 | 3,500円 |
| 入居日 | 月の1日 |
| 敷金 | 0円 |
| 礼金 | 127,500円 |
| クリーニング費 | 80,000円 |

礼金は物件によって異なり、クリーニング費は間取りなどによって金額が変わります。

そのため、以下の金額はすべての大東建託物件に共通する金額ではなく、家賃8万5,000円の物件を月の1日から契約する場合の一例です。

## ① 大東建託パートナーズに支払う初期費用 {#partners}

まずは、大東建託パートナーズに支払う費用です。以下の表の日付はいずれも2027年の入居申込日です。

| 項目 | 1月11日まで | 1月12日から |
| --- | ---: | ---: |
| 礼金 | 127,500円 | 127,500円 |
| 敷金 | 0円 | 0円 |
| クリーニング費 | 80,000円 | 80,000円 |
| 契約時保証委託料 | 25,000円 | 77,904円 |
| 鍵セット費 | 3,300円 | 3,300円 |
| 火災保険料 | 0円 | 0円 |
| **合計** | **235,800円** | **288,704円** |

### 敷金

大東建託物件に敷金はかかりません。

今回の物件だけでなく、すべての大東建託物件で敷金は0円です。

敷金の代わりに、契約時にクリーニング費を支払う形になっています。

### クリーニング費

今回のクリーニング費は8万円です。

クリーニング費は間取りなどによって金額が変わるため、物件情報や見積書で確認する必要があります。

### 契約時保証委託料

2027年1月11日までの入居申込分は、ペット不可物件が22,000円、ペット共生物件が25,000円です。1月12日以降の対象物件は、どちらも賃料総額の80％になります。

今回の例では、家賃・駐車場使用料・共益費・ruumサポート・町内会費の合計97,380円を計算対象とします。改定後の契約時保証委託料は、97,380円×80％＝77,904円です。[ハウスリーブの改定内容と賃料等6万円の例](/column/daito-houseleave-20270112/)

### 鍵セット費

鍵セット費は3,300円です。

### 火災保険料

大東建託物件では、火災保険料は不要です。

今回の物件だけでなく、すべての大東建託物件で別途の火災保険料はかかりません。

## ② 前家賃 {#advance-rent}

次に、入居する月の家賃や月額費用です。

今回は月の1日から入居するため、日割りではなく1カ月分で計算します。

| 項目 | 1月11日までの申込み | 1月12日からの申込み |
| --- | ---: | ---: |
| 家賃 | 85,000円 | 85,000円 |
| 駐車場使用料 | 6,600円 | 6,600円 |
| 共益費 | 3,500円 | 3,500円 |
| ruumサポート | 1,980円 | 1,980円 |
| 町内会費 | 300円 | 300円 |
| 月額保証委託料 | 2,434円 | 2,921円 |
| **合計** | **99,814円** | **100,301円** |

月額保証委託料は、97,380円にペット共生物件の料率（改定前2.5％・改定後3％）を掛け、1円未満を切り捨てて試算しています。[ハウスリーブ「保証委託契約約款」第3条（PDF）](https://www.house-leave.com/news/img/20260113/2.pdf)

月の途中から入居する場合は、契約開始日によって家賃などの計算が変わります。

同じ物件でも入居日が違えば初期費用の総額も変わるため、見積もりを比較するときは入居日をそろえる必要があります。

## ③ 仲介業者に支払う費用 {#agency}

最後に、窓口となる仲介業者へ支払う費用です。

| 項目 | 計算方法 | 金額 |
| --- | --- | ---: |
| 仲介手数料 | 家賃85,000円×1.1 | 93,500円 |
| 駐車場手数料 | 駐車場6,600円×1.1 | 7,260円 |
| その他オプション | 仲介業者による | 未定 |
| **オプションを除く合計** |  | **100,760円** |

大東建託物件の場合、仲介手数料は家賃の1.1カ月分、駐車場手数料は駐車場代の1.1カ月分となっていることが多いです。

ただし、実際の金額や条件は仲介業者によって異なります。

また、仲介業者によっては、次のようなオプションが見積もりに含まれることがあります。

- 抗菌施工
- 害虫駆除
- 消火用具
- その他の入居サポート

これらのオプション内容や金額も、仲介業者によって変わります。

## 初期費用の合計は、申込日でいくら変わる？ {#total}

ここまでの金額を、入居申込日ごとに合計します。

| 支払先・費用 | 1月11日まで | 1月12日から |
| --- | ---: | ---: |
| ① 大東建託パートナーズに支払う費用 | 235,800円 | 288,704円 |
| ② 前家賃 | 99,814円 | 100,301円 |
| ③ 仲介業者に支払う費用 | 100,760円 | 100,760円 |
| **合計** | **436,374円** | **489,765円** |

このペット共生物件では、改定後の初期費用が**53,391円**高くなります。内訳は契約時保証委託料の差52,904円と、前家賃に含まれる月額保証委託料1カ月分の差487円です。抗菌や害虫駆除などの追加オプションは含めていません。

同じ家賃・諸費用のペット不可物件で、月額料率が2.2％から2.5％に変わる場合は、改定前が433,082円、改定後が489,278円です。

## 初期費用を比較するポイント {#comparison}

大東建託物件の見積もりを比較するときは、すべての費用が変わるわけではありません。

### どこで借りても基本的に同じ部分

同じ物件・同じ入居日・同じ契約条件であれば、次の部分は基本的に同じです。

- 大東建託パートナーズに支払う費用
- 家賃
- 駐車場使用料
- 共益費
- ruumサポート
- 町内会費
- 月額保証委託料

### 仲介業者によって変わる部分

比較するべきなのは、主に次の部分です。

- 仲介手数料
- 駐車場手数料
- 抗菌施工
- 害虫駆除
- その他のオプション費用

見積書を比較するときは、総額だけを見るのではなく、①②③に分けて確認すると、どの部分に差があるのかが分かりやすくなります。

## まとめ

大東建託物件の初期費用は、次の3つでできています。

1. 大東建託パートナーズに支払う初期費用
2. 前家賃
3. 仲介業者に支払う費用

家賃85,000円のペット共生物件を上の条件で試算すると、オプションを除く合計は、2027年1月11日までの申込みで436,374円、1月12日以降の申込みで489,765円です。

同じ物件を同じ条件で借りる場合、①と②はどの窓口でも基本的に同じです。

初期費用に差が出やすいのは、③の仲介手数料・駐車場手数料・抗菌や害虫駆除などのオプションです。

大東建託物件の初期費用を比較するときは、仲介業者へ申し込む前に、③の内容を確認することが大切です。

※掲載している合計金額は一例です。礼金、クリーニング費、月額費用などは物件や契約条件によって異なります。敷金はすべての大東建託物件で0円、火災保険料は不要です。
